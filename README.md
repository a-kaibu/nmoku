# nmoku

N目並べ：勝つたびに自分だけ条件が厳しくなる五目並べ。

**遊ぶ:** https://a-kaibu.github.io/nmoku/

## ルール

- 15×15 の盤に交互に石を置き、自分の目標数以上を縦・横・斜めに並べたらラウンド勝利
- 両者とも 4目 からスタート。ラウンドに勝つと自分の目標だけが 1 増える（4→5→6）
- 目標 6目 の状態でラウンドに勝てば優勝
- 負けた側が次のラウンドの先手。盤が埋まったら引き分けで目標はそのまま

## 開発

[Vite+](https://viteplus.dev/)（`vp`）を使っています。

```bash
vp install   # 依存関係のインストール
vp dev       # 開発サーバー
vp check     # フォーマット・lint・型チェック
vp test      # テスト
vp build     # dist/ にビルド
```

| ファイル        | 役割                                                |
| --------------- | --------------------------------------------------- |
| `src/game.ts`   | ルール（盤面・勝敗判定・Nの繰り上がり・先手の決定） |
| `src/ai.ts`     | CPU の思考（各マスを含む長さ N の窓で攻守を評価）   |
| `src/render.ts` | canvas での盤面描画                                 |
| `src/main.ts`   | 画面と入力のつなぎ込み                              |

main に push すると GitHub Actions がチェック・テスト・ビルドをして GitHub Pages にデプロイします。
